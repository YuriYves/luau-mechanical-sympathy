# Luau Mechanical Sympathy
A skill for agents designed for superoptimization, as an exercise in mechanical sympathy.

## Installation
null

## Usage
The tools extract the bytecode from the Luau code to perform a score-based analysis, and then provide a condensed view by means of a JSON table. A very high score indicates code that requires a significant amount of additional processing time.
